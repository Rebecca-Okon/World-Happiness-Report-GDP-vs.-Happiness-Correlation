Project 10: World Happiness Report – GDP vs. Happiness
Correlation

Dataset: World Happiness Report (Kaggle)
Introduction:
The World Happiness Report ranks countries based on factors like GDP, social support, and life
expectancy. This project explores how economic and social factors influence happiness scores.

Key Questions to Answer:
1. Which countries rank highest in happiness, and why?
2. Is there a strong correlation between GDP per capita and happiness?
3. How do social support, freedom, and corruption perceptions impact happiness?
4. Has global happiness improved over the years?
   
Tasks to Perform:
● Merge multiple years of happiness data.
● Perform correlation analysis (heatmaps, scatter plots).
● Cluster countries based on happiness drivers.

Deliverables:
● Jupyter Notebook with statistical analysis.
● Report with policy recommendations.
● Dashboard (optional, using Dash/Tableau).
